Privacy policy

Last updated: 13 November 2026

What S2dio is

S2dio is a personal tool used only by its owner to upload and schedule their own videos to their own YouTube channel and Instagram account.

What data it uses

  • With the owner's permission, S2dio uses Google's YouTube Data API to upload videos and to read the name of the owner's channel.
  • Sign-in tokens are stored only on the owner's computer. They are never sent to any server other than Google's (or Meta's, for Instagram).
  • S2dio does not collect, sell, share or analyse data about any other person.

Google API Services

S2dio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. S2dio uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can remove S2dio's access at any time at myaccount.google.com/permissions, which stops all uploads.
